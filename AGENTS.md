# Wake4You

Рабочая версия сайта находится в `prototype/`. Для правок главной открывай `prototype/index.html`. Стили и скрипты отдельных сцен лежат в `prototype/assets/`. Файл `index.html` в корне репозитория относится к ранней версии.

Перед правкой прочитай `PROJECT_CONTEXT.md` и сверь описание с текущей разметкой. Материалы сайта доступны в Git по относительным путям. Для работы над мобильной версией используй существующие адаптивные стили.

Из корня репозитория запусти `node prototype/server.mjs`. Предпросмотр открывается на `http://127.0.0.1:4174/`. Для запуска сайта нужен только Node.js. После правки проверь изменённую сцену в мобильном и десктопном размерах.
